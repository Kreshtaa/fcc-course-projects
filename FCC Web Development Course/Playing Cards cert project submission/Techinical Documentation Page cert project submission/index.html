What is KreshEdit?

KreshEdit is a modular, private save editor for visual novels, interactive novels, and other small games.

It runs entirely in your browser - no installs, no servers, no data ever leaves your machine.

Architecture

KreshEdit features a robust modular architecure. This makes adding new modules relatively simple in principle. Each module follows the same Detect > Decode > Encode pattern outlined in module_template.js. The full outline of the project files can be found below:


  KreshEdit/
      ├── index.html
      ├── main.js
      ├── style.css
      └── modules/
          ├── _utils.js          — shared helpers + pako loader (window.KreshUtils, window.KreshPako)
          ├── module_template.js — copy this to add a new format
          ├── sugarcube.js
          ├── rpgmaker_mv.js
          ├── gzip_json.js
          ├── renpy.js
          ├── unity_json.js
          ├── unreal_json.js
          ├── lzstring.js
          └── html.js
Supported formats

The current list of supported formats and encodings is as follows, in the format Format: Encodings

  • SugarCube/Twine: Plain JSON, Base64 JSON, Base64 + zlib JSON
  • RPGMaker MV/MZ: Base64 + zlib JSON
  • Ren'Py: Pickle (raw + gzip) via Pyodide
  • Unity JSON: Plain JSON, Base64 JSON
  • Unreal JSON: Plain JSON
  • LZString: compressToBase64, compressToEncodedURIComponent
  • Gzip JSON: Raw gzip-compressed JSON
  • Generic JSON: Plain JSON, Base64 JSON

Binary formats (Unreal GVAS, Unity binary serialization, RAGS) are not supported.

Ren'Py support is experimental. Saves composed of standard dicts, lists, and primitives round-trip cleanly. Custom Python classes are represented as annotated JSON and restored as plain dicts — exact fidelity is not guaranteed for all games.

Due to the modular nature of this tool, this list is not definitive and can be added to relatively easily if need be.

Adding new modules

As previously mentioned, since this tool is built in a modular fashion, new modules can be added if need be by following the following instructions.

Copy modules/module_template.js, rename it, and implement these three functions:

  1. function detect(buffer) → boolean (sync, must not throw)
  2. function decode(buffer) → { text, metadata } (may be async, may throw)
  3. function encode(text, metadata) → Uint8Array (may be async, may throw)

Then do the following:

  1. Add a <script> tag for your file in index.html (before main.js).
  2. Add the module name to MODULE_NAMES in main.js. Order matters — more specific formats before broader ones.

How to use it?

The tool can be used either online or locally. The hosted version can be found at editor.kreshy.com. All processing is done locally so no data leaves your browser.

Alternatively, as mentioned, this tool can be used locally. You may have to use a local HTTP server to do this since some browsers reject CDN requests or file access when opening index.html locally via file://.

Therefore to run the tool locally first run python3 -m http.server in your terminal from the KreshEdit directory, and then open http://localhost:8000 in your browser. This method requires python3 to be present on your system.
